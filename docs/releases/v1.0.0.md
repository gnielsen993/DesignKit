# v1.0.0

Date: in progress
Type: major (first stable tag)

## Summary
- First stable tag of **DesignKit** — a shared SwiftUI design system
  Swift Package providing semantic tokens (color / typography /
  spacing / radii / motion), a preset catalog, ThemeManager, and
  reusable components. Consumed by GameKit, FitnessTracker,
  HabitTracker, PantryPlanner.

> v1.0.0 was developed before this release-log convention existed.
> Detailed rationale lives in `Architecture_Constitution.md`,
> `PRODUCTION_THEME_NOTES.md`, and the `Plan*.md` files. This file
> captures the shipping shape; future tagged versions populate the
> log natively.

## API changes
- **Tokens:** color (`theme.colors.*`), typography (`theme.typography.*`),
  spacing (`xs / s / m / l / xl / xxl`), radii (`card / button / chip /
  sheet`), motion, chart opacities (`theme.charts.{axisLabelOpacity,
  gridlineOpacity}`).
- **Theme system:** `ThemeManager` (mode + preset + overrides + saved
  customs), `PresetCatalog.core` (5 luxury swatches) and
  `PresetCatalog.all` (34-preset full catalog including cream, paper,
  sand, roseDawn, sage, serika, charcoal, nord, dracula, gruvbox,
  forestNight, midnight, oxblood, etc.), `ThemePreset.classicMuted`
  ("Chrome Diner" — cream + brushed grey + diner red).
- **Components:** `DKCard`, `DKButton`, `DKProgressRing`, `DKBadge`,
  `DKSectionHeader`, `DKThemePicker(catalog:maxGridHeight:)`.
- **Charts:** Swift Charts styling helpers honoring theme opacities.

## Internal changes
- Folder layout: `Theme / Typography / Layout / Motion / Components /
  Charts / Storage / Utilities` per CLAUDE §3.
- Custom-mode chart palette follows overridden accent (regression
  fixed prior to v1.0.0 tag).
- Per-preset palette additions for `theme.gameNumber(_:)` token with
  XCTest contracts.

## Fixes
- Custom-mode chart palette no longer ignores user accent override.

## Consumer migration notes
- GameKit / FitnessTracker / HabitTracker / PantryPlanner: pin
  `Package.swift` to `from: "1.0.0"`.
- Verify each app reads radii from `{card, button, chip, sheet}` only
  (no `.medium` / `.small`) and spacing from the 6-step scale.

## Risks / notes
- This is the first tag — no prior version exists to migrate from.
- Future major bumps should remove no public API without a one-tag
  deprecation cycle.
